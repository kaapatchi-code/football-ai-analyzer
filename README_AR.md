# FOOTBALL AI ANALYZER

موقع ويب محلي لتحليل مباريات كرة القدم. النسخة الحالية تتضمن واجهة عربية، البحث عن الأندية عبر API-Football عند إعداد المفتاح، جلب آخر 10 مباريات، واستخراج مؤشرات النتائج والأهداف والشوطين واحتساب نموذج Poisson مبسط عند توفر عينة كافية.

## التشغيل على Windows
1. ثبّت Python 3.10 أو أحدث.
2. فك ضغط المشروع.
3. افتح مجلد المشروع، ثم اكتب `cmd` في شريط عنوان File Explorer واضغط Enter.
4. نفّذ:

```bat
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

5. افتح ملف `.env` وضع مفتاح API-Football مكان `ضع_مفتاحك_هنا`.
6. شغّل:

```bat
python app.py
```

7. افتح `http://127.0.0.1:5000` في Chrome.

يمكنك أيضاً تشغيل `START_WINDOWS.bat` لتثبيت المتطلبات وفتح الموقع تلقائياً. في أول تشغيل سيفتح ملف `.env` لتضع مفتاحك. لا ترسل المفتاح في المحادثات ولا تضعه داخل ملفات HTML أو JavaScript؛ ضعه فقط في `.env` على جهازك.

## البيانات ومصادرها
- مزود البيانات المباشر: API-Football / API-Sports. يتطلب مفتاح API وقد يتطلب اشتراكاً مناسباً لبعض المسابقات والميزات.
- لا يوجد مفتاح API مضمّن في المشروع.
- بدون المفتاح، ستعمل الواجهة وتعرض طريقة الإعداد، لكن البحث المباشر والتحليل الحي لن يعملا.
- يسترجع البرنامج قائمة الإصابات، ومتوسط الركنيات والبطاقات من عينة آخر 5 مباريات عندما تكون هذه البيانات متاحة ضمن اشتراك المزود. xG يعرض فقط إذا أعاد المزود الحقل صراحةً. التشكيلات الرسمية، ترتيب المجموعة، دافع التأهل، أسعار المراهنات، بيانات اللاعبين التفصيلية والطقس ليست متصلة بعد.

## ترشيد استهلاك الحصة
- أضيف تخزين مؤقت في ذاكرة الخادم: بحث الفرق 24 ساعة، المباريات ساعة، إحصائيات المباراة 24 ساعة، والإصابات 30 دقيقة. يساعد ذلك على تقليل تكرار الطلبات عند إعادة التحليل.
- أول تحليل قد يستهلك عدة طلبات (مباريات الفريقين، عينة إحصائيات، والإصابات). راقب الحصة من لوحة API-Sports، ولا تكرر التحليل بلا حاجة.
- التخزين المؤقت الحالي يختفي عند إغلاق الخادم أو إعادة تشغيله.

## حدود النسخة الأولى
- يعتمد نموذج Poisson الحالي على متوسط الأهداف المسجلة والمستقبلة في آخر 10 مباريات، مع أفضلية أرض افتراضية بسيطة. هو نموذج أولي وليس نموذجاً احترافياً معايراً.
- لا يستخدم xG الحقيقي ولا قوة الخصوم ولا الغيابات ولا التشكيلات ولا الأسعار.
- لا يثبت التلاعب أو بيع المباريات. أي حركة سوق غير عادية تحتاج مصادر مستقلة وتحقيقاً موثوقاً.
- النسب ليست ضماناً ولا توصية مالية.
